## Featured Projects

### [Cartzy — E-Commerce Platform](https://ecommerce-site-roan-gamma.vercel.app)

> React · Tailwind CSS · React Router v6 · Clerk · EmailJS · Vite · Vercel

A production-deployed e-commerce web app with a full shopping experience.

- Product grid with category and price filters, cart with quantity controls and order summary
- Clerk authentication with conditional rendering based on auth state
- Working EmailJS contact form — sends real emails, no backend required
- Dark/light theme applied globally across all components
- Location detection via browser Geolocation API + Nominatim reverse geocoding
- Hero carousel built with Swiper.js, infinite category marquee, JS parallax mid-banner
- Checkout stepper (Cart → Shipping → Payment) with free shipping threshold logic
- Fully responsive — mobile drawer nav, collapsible filter sidebar

**[Live Demo](https://ecommerce-site-roan-gamma.vercel.app) · [Source Code](https://github.com/anjumhere/Ecommerce-website-react)**
